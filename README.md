# 🎂 Bolos da Margarete

Bem-vindo ao site oficial de **Bolos da Margarete** - O seu lugar especial para bolos feitos com amor e qualidade!

## 📋 Sobre o Projeto

**Bolos da Margarete** é um site moderno e responsivo que apresenta os deliciosos bolos artesanais criados com dedicação. Aqui você encontrará uma seleção especial de sabores, receitas tradicionais e tudo o que você precisa para saborear um bolo verdadeiramente especial.

## ✨ Características

- 🎨 **Design Responsivo** - Funciona perfeitamente em dispositivos mobile, tablet e desktop
- 🍰 **Catálogo Completo** - Apresentação detalhada de todos os sabores disponíveis
- 📱 **Interface Intuitiva** - Navegação fácil e agradável
- 🎯 **Otimizado** - Carregamento rápido e performance excelente
- 💬 **Contato Fácil** - Formas simples de entrar em contato para fazer pedidos

## 🚀 Como Usar

### Visualizar o Site
1. Acesse o repositório no GitHub
2. Abra o arquivo `index.html` no seu navegador
3. Explore os diferentes sabores e informações

### Fazer um Pedido
- Navegue pela seção de catálogo
- Escolha o seu bolo favorito
- Entre em contato através do formulário de pedidos

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica do site
- **CSS3** - Estilização moderna e responsiva
- **JavaScript** - Interatividade e funcionalidades dinâmicas
